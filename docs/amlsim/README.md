# AMLSim 反洗钱强化学习案例

本目录保存 2026-10-21 完成的受控反洗钱规则实验。案例目标不是证明某一算法普遍优越，而是验证一套可审计闭环：规则来源确认、确定性数据生成、SFT 输出对齐、GRPO/NGRPO 训练、Rollout 实时诊断、独立测试复评和结论沉淀。

## 研究结论摘要

- 数据依照实验前定义的专家规则生成，标签和证据交易 ID 在生成时确定，不依赖教师模型或训练后人工评分。
- `FAN_IN`、`FAN_OUT`、`CYCLE` 的方向性语义来自 IBM AMLSim；四账户阈值、48/72 小时时窗、NORMAL 负例、类别配比、输出格式和 Reward 权重由本实验定义。
- Base 模型格式有效率为 100%，但风险召回率仅 7.83%，因此主要问题是漏报，不是格式解析失败。
- 初始 SFT 的低验证损失没有转化为可控生成；定位到 VERL SFT EOS token 被 loss mask 排除。修复后风险准确率达到 89.75%。
- 修复 Reward 重复证据漏洞后，GRPO step 5 风险准确率达到 96.88%，但训练 Rollout 中可产生组内相对优势的 group 降到 0%。
- NGRPO step 5 将风险准确率提高到 98.62%，误报从 25 降至 11；但类型准确率低于 GRPO，`FAN_OUT` 从 99.00% 降至 82.50%。因此不能概括为“NGRPO 全面优于 GRPO”。

## 文档导航

- `EXPERT_RULES_AND_DATASET.md`：上游来源、专家规则、数据生成机制、哈希和适用边界。
- `EXPERIMENT_PROTOCOL.md`：研究问题、基线、预期、模型、镜像、训练与评测参数。
- `RESULTS_AND_FINDINGS.md`：完整结果、诊断证据、指标解释、有效性威胁与结论。
- `REPRODUCTION.md`：其他 agent 从代码到结果的复现步骤与验收条件。
- `results/`：小型标准化结果、运行清单、Rollout 汇总和 PPT 图表。

## 证据级别

- `已直接测量`：来自 800 条独立测试集、训练日志或保存的 Rollout。
- `代码定位`：通过源码和可复现实验定位，例如 EOS loss mask 与 Reward 重复 ID 漏洞。
- `解释性推断`：由观测支持但不能单独证明因果，例如“组内信号饱和可能限制继续训练收益”。

大型 Parquet、完整预测 JSONL、训练日志、模型权重和检查点不进入 Git。数据可由确定性生成器和哈希复核，评测结果可由相同 checkpoint 重新生成。
