# AMLSim 短训练与长训练阶段性对比

更新时间：2026-10-31

## 1. 对比目的

本文件用于回答三个问题：

1. 150 步长训练相比此前 5 步短训练提升了什么；
2. 当前结果能否证明 NGRPO 优于 GRPO；
3. NGRPO 在独立测试集达到接近 100% 是否意味着过拟合。

所有已列指标均来自同一套 800 条 AMLSim 合成独立测试集。该测试集包含 `CYCLE`、`NORMAL`、`FAN_IN`、`FAN_OUT` 各 200 条。

## 3. 分类指标变化

| 实验 | CYCLE | NORMAL | FAN_IN | FAN_OUT |
|---|---:|---:|---:|---:|
| SFT step30 | 96.0% | 59.0% | 100% | 100% |
| GRPO step5 | 100% | 87.5% | 100% | 99.0% |
| NGRPO step5 | 98.5% | 94.5% | 100% | 82.5% |
| NGRPO step150 | 100% | 100% | 100% | 99.5% |

短 NGRPO 的总体风险指标优于短 GRPO，但 `FAN_OUT` 从 GRPO 的 99.0% 降至 82.5%。因此，5 步实验不能支持“NGRPO 全面优于 GRPO”的结论。150 步 NGRPO 最终修复了该类别退化，并在当前测试集上达到近饱和性能。

## 4. 长训练带来的实际变化

NGRPO step150 相比 NGRPO step5：

- 风险准确率从 98.625% 提升至 100%；
- 类型准确率从 93.875% 提升至 99.875%；
- 证据 F1 从 98.250% 提升至 99.961%；
- 风险误报从 11 条降至 0 条；
- `FAN_OUT` 准确率从 82.5% 提升至 99.5%。

长训练的主要收益不是简单提高二分类准确率，而是修复短训练阶段被总体指标掩盖的类型退化。

## 5. 训练过程并非单调改善

独立测试结果在 step25、step50、step75、step100、step125、step150 之间存在明显波动：

- step25 出现 50 条漏报，风险准确率下降至 93.75%；
- step50 后快速恢复到 99% 以上；
- step100 已达到 99.875%；
- step125 短暂下降至 99.375%；
- step150 最终达到风险识别 100%。

因此，平均 Reward 上升、训练 Rollout 全对或最终 checkpoint 更晚，都不能单独证明模型一定更好。必须使用固定独立测试集评测 checkpoint。

训练日志还显示后半程存在较明显的任务饱和：150 步中约 89 步平均 Reward 达到满分，约一半 step 的梯度接近零。step100 之后的边际收益已经很小。

## 6. 100% 结果的解释边界

当前结果不属于简单的训练样本重复：训练集和测试集使用不同随机种子、不同 case ID、不同账户与交易编号。

但训练集和测试集来自同一个确定性生成器，并共享：

- 相同的专家规则；
- 相同的 Prompt 模板；
- 相同的类别平衡方式；
- 相同的噪声构造方法；
- 相同的时间窗口和账户数量范围；
- 相同的 NORMAL 负样本类型。

因此，更合理的判断是：模型已经近乎完全拟合当前生成器的同分布任务。该结果证明训练链路、Reward 和诊断工具能够工作，但不能直接外推为真实银行反洗钱数据上的 100% 准确率。

## 7. 同预算 GRPO 与 NGRPO 结论

匹配配置的 GRPO 150 步实验已经完成。结果不支持“NGRPO 在所有阶段都优于 GRPO”：

- step25 至 step75，GRPO 的独立测试指标明显高于 NGRPO；
- step100，两种算法的风险和类型准确率均为 99.875%；
- step125，GRPO 仍略高于 NGRPO；
- step150，GRPO 回退到 99.25%，NGRPO 达到风险识别 100%。

当前更准确的结论是：

> GRPO 在当前任务上收敛更快，约在 step75 达到峰值，但继续训练后出现性能回退；NGRPO 前期收敛更慢、波动更大，但最终 checkpoint 的保持能力更好。

因此，NGRPO 的优势更接近“长训练末期的性能保持和恢复”，而不是“更快或始终更充分地学习生成器”。若采用独立评测早停，GRPO step75/100 与 NGRPO step100/150 都已接近任务上限。

## 8. 后续重复实验的判定标准

需要同时比较以下指标：

1. 达到 99% 风险准确率和类型准确率所需的训练步数；
2. 各 checkpoint 的总体指标与四类指标；
3. 有效 Group、非零 Advantage 和实际更新样本比例；
4. 全对、全错和接近全对/全错 Group 的变化；
5. Reward、KL、Grad Norm 和 Clip Fraction 的稳定性；
6. 不同随机种子下结果是否可复现。

本轮结果显示 GRPO 更早达到目标，而 NGRPO 的最终 checkpoint 更好。只有在多个随机种子中重复出现相同趋势，才能将其描述为稳定的算法差异。单次实验仍可能受到采样顺序和 checkpoint 波动影响。

## 9. 建议增加的泛化测试

为了区分“学会专家规则”和“学会数据生成器固定模式”，建议建立独立 OOD 测试集：

- 改写 Prompt 和规则描述顺序；
- 改变账户数量、噪声比例、交易顺序和时间跨度；
- 增加接近阈值但不命中规则的困难负样本；
- 增加同时接近多种类型的混淆样本；
- 增加缺失交易、重复交易和异常时间戳；
- 使用不同生成程序或人工构造案例；
- 至少使用三个随机种子重复 GRPO/NGRPO 对照。

## 10. 阶段性结论

本轮同预算实验表明：GRPO 和 NGRPO 都能在当前确定规则的合成任务上达到接近饱和的性能，但最佳 checkpoint 并不一定是最后一个 checkpoint。GRPO 收敛更快并在 step75/100 达到峰值，step150 出现回退；NGRPO 前期波动更明显，但 step150 最终结果最好。工具能够通过 Rollout 趋势与 checkpoint 独立评测发现训练饱和、类别退化和末期回退。算法结论仍需多随机种子和 OOD 泛化测试验证。
