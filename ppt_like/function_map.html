十二项功能 · 四类能力

RL Training Toolkit 的功能组成

工具不是单一看板，而是围绕 RL 实验建立四类能力：接入事实、观察过程、解释问题、支持训练决策。

数据接入

Data Ingestion
01 / 03

1. 训练日志解析

解析训练进度、Reward、KL、Entropy、梯度、截断率和错误信息。

2. Rollout 数据解析

读取 Prompt、Output、Reward、Advantage、预测结果和格式状态。

3. 实验管理与归档

记录实验配置、版本、环境和结果，并支持实验对比、导出和导入。

作用：把分散在训练目录、日志文件和 Rollout 文件中的实验事实统一纳入工具。

过程监控

Process Monitoring
02 / 03

4. 浏览器前端看板

展示实验列表、训练指标、告警、Group 信号和 Rollout 证据。

5. Jupyter 实时监控

在 Notebook 中查看训练趋势、Rollout、实验对比和稳定性规则。

6. Rollout 质量诊断

检查空输出、无效 JSON、Schema 错误、格式错误和输出截断。

7. 训练稳定性监控

检测 Reward 退化、KL 漂移、梯度异常、Clip 饱和和策略退化。

作用：让研发人员在训练过程中及时看到状态变化，而不是训练结束后才读取结果。

问题诊断

Behavior Diagnosis
03 / 03

8. Prompt Group 分析

恢复同一 Prompt 的多条回答，分析全对、全错、混合和有效 Group。

9. 领域任务评测

支持数学、代码、金融风控、FinQA、AMLSim 等任务评估。

10. 离线诊断与报告生成

输出 CSV、JSON、HTML 报告、SVG 图表和异常样本。

作用：从“指标发生变化”进一步定位到“模型行为发生了什么、可能为什么发生”。

训练支撑

Training Support
04 / 03

11. VERL Rollout 证据补丁

为 Rollout 补充 uid、算法信息、Advantage 等训练证据。

12. NGRPO 运行时补丁

为 VERL 增加 NGRPO 支持，并提供应用、检查和恢复能力。

说明：这里将实验管理与归档作为数据接入的一部分；训练支撑强调对 VERL 训练运行时的直接支持。

从原始训练数据到可执行实验结论：接入 → 监控 → 诊断 → 训练支撑
